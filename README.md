**Quillvibe** is a free, open-source book writing app built for authors and writers. You can write chapters, keep character and world notes, mark up drafts while proofreading, design book covers, and export print-ready `.pdf` and `.epub` books—all in one place without creating an account. It opens in **Ivory Light** with three **Workspace Layouts** (**Focused**, **Editorial**, and **Full Studio**), works offline, saves books in Quillvibe's protected `.qv` format, and is published under **`jhonrey.com`**.

## 1. Why Keep Everything in One Place

Many writers end up juggling several separate programs—one for writing chapters, another for outlines, another for character notes, another for cover design, and another to turn drafts into an eBook or print PDF. Quillvibe keeps all of those steps together in one local book file:

- **No account and no setup**: Open a blank book or sample project right away. Your `.qv` file stays on your own device and can be locked with a password.
- **Comfortable for quick notes or full series**: Write freely without distracting red underlines (spellcheck is off by default and toggleable in Settings), use **Universal Search (`Ctrl/Cmd + K`)** to jump straight to any scene, tool, FAQ, or Academy lesson, pick **Match Device (System)**, **Ivory Light**, **Parchment**, or **Obsidian Dark** themes—or **link App Theme & Manuscript Paper Theme** so changing one updates both—toggle **Smooth Animations**, lock finalized proofread chapters or parts against accidental edits, use dedicated full pages for `/settings` and `/manual`, and undo/redo with `Ctrl+Z` / `Ctrl+Y`.
- **Images right inside your book**: Drag and drop or insert photos and illustrations into any scene, wrap text around them (**Wrap Left**, **Wrap Right**, **Top & Bottom**, **Inline**, **Behind Text**), snap to grid or alignment guides, and remove solid backgrounds offline with one click.
- **Unified Draft Mode & built-in proofreading marks**: Toggle **Proofread** (15 copyediting symbols with Clean Preview and automatic snapshots) alongside a resizable **Split Reference** and **Revision Diff** pane directly inside Draft Mode without leaving your writing sheet.
- **Ready for publishing & easy `.docx` migration**: Add your publisher name, ISBN, custom fonts (`.ttf`, `.otf`, `.woff`, `.woff2`), front/spine/back book covers, Origin Author Keys, Work Copyright Seals, verified co-author access, type-to-confirm safe book deletion, and export full **`.docx`** manuscripts (for standard word processors and cloud document editors), `.md`, `.rtf`, or `.json`.

## 2. How to Use in Your Browser or Install on Desktop

### Option A: Use the Website Version (No Download Needed)
Visit <a href="https://quillvibe.jhonrey.com/" target="_blank" rel="noopener noreferrer"><strong>https://quillvibe.jhonrey.com/</strong></a> (new visitors start at `/start`; returning writers go straight to `/write`) to write, add images with text wrap & background removal, organize notes, proofread, design covers, and export `.qv`, `.pdf`, `.epub`, or `.md` files right in your web browser.
- This is the easiest way to try Quillvibe without installing anything or dealing with desktop security prompts.
- The browser version has fewer features than the installed desktop app. Remember to click **Save** to download a `.qv` backup file to your computer when you finish writing.

### Option B: Install on Windows, macOS, Linux, Chromebook & Other OS
Download the latest installer from <a href="https://github.com/jhonrey-com/Quillvibe/releases/latest" target="_blank" rel="noopener noreferrer"><strong>GitHub Releases (<code>v3.3.7</code>)</strong></a> (published under **`jhonrey.com`**):
- **Windows:** `.msi` or branded `-setup.exe` (x64, with custom app icon & **Check for Updates** inside `/settings`)
- **Mac (Apple Silicon & Intel):** Universal `.dmg` (`arm64` + `x86_64`)
- **Linux (x64 & ARM64):** `.AppImage`, `.deb`, or `.rpm`
- **Chromebook (ChromeOS):** Open <a href="https://quillvibe.jhonrey.com/" target="_blank" rel="noopener noreferrer"><strong>quillvibe.jhonrey.com</strong></a> in Chrome and click **Install app** in the address bar for full offline desktop-like use (or install the `.deb` x64/ARM64 package inside Chromebook Linux / Crostini)
- **Other OS (Android, iPadOS, iOS, BSD & Any Modern Browser):** Install directly as an offline Web App (`Add to Home Screen` / `Install app`) from <a href="https://quillvibe.jhonrey.com/" target="_blank" rel="noopener noreferrer"><strong>quillvibe.jhonrey.com</strong></a> with local `.qv` storage and full export support

Because Quillvibe is a new open-source app still being actively updated and improved, Windows, Mac, or Linux may show a warning before opening the installer. If you prefer to avoid that prompt, you can use the website version above instead.

Desktop builds add automatic saving to your computer, stacked book tabs driven by a central drag-and-drop state machine (horizontal strip reordering, vertical tear-off detachment while preserving cursor grab offset, sole-tab window dragging, and z-ordered window merging), an empty **New Tab** book picker (`Ctrl+Shift+N`), conflict-safe live multi-window sync, single-instance double-click opening into a new tab for `.qv`, `.qvbible`, `.qvscene`, `.qvstyle`, and `.qvdesign` files, the **Pro Vector Book Cover Studio** (freehand brush & vector pen drawing, 7 optical blend modes, direct HTTPS image URL pasting, side-by-side draft comparison, canvas review pins, and `.qvdesign` sharing), `F11` fullscreen focus mode with a clock/timer bar, in-app update checking, and Wi-Fi/Bluetooth book sharing.

### Option C: Terminal Installers

**Windows (PowerShell):**
```powershell
irm https://raw.githubusercontent.com/jhonrey-com/Quillvibe/main/scripts/install.ps1 | iex
```
*(Or Winget manifest `packaging/winget/jhonrey.Quillvibe.yaml`.)*

**macOS & Linux:**
```bash
curl -fsSL https://raw.githubusercontent.com/jhonrey-com/Quillvibe/main/scripts/install.sh | sh
```
*(Or Homebrew Cask via `packaging/homebrew/quillvibe.rb`.)*

### Option D: One-Click Repo Launchers & Source Build
- **Windows / macOS / Linux repo launchers:** `Start-Quillvibe.bat`, `Start-Quillvibe.command`, or `./start-quillvibe.sh`
- Requirements from source: Node.js 20+ (and Rust toolchain for `npm run tauri:build`)

```bash
git clone https://github.com/jhonrey-com/Quillvibe.git
cd Quillvibe
npm install

# Start browser UI preview at http://localhost:1420
npm run dev

# Build isolated web (dist/) or desktop (dist-desktop/) frontend targets
npm run build:web
npm run build:desktop

# Run or package the native Rust/Tauri desktop application
npm run tauri:dev
npm run tauri:build
```

## 3. Guides by Workspace Layout (Focused, Editorial, Full Studio)

Switch layouts anytime in **Settings -> Workspace & Editor** or by clicking the **Workspace** button in the bottom-left bar. Changing layouts only shows or hides panels—it never deletes any of your work.

### Focused — Clean Page for Drafting
1. Open Quillvibe. The Welcome screen lets you start a blank book, open the sample book, open a `.qv` file, or read the built-in writing course at `/course`.
2. Write directly on **Ivory**, **Parchment**, or **Obsidian** paper with simple formatting (`Ctrl/Cmd+B`, `Ctrl/Cmd+I`, headings, quotes, scene breaks).
3. Pick your preferred save format (`.qv`, `.pdf`, `.epub`, `.md`, `.qvscene`) and click **Save**.

### Editorial — Outlining, Proofreading & Interior Print Layout
Switch to **Editorial** layout to add **Corkboard** scene cards, **Outline** view, **Proofread** markup (15 copyediting symbols with Clean Preview and revision snapshots), and **Interior Typeset** for print and eBook layout.

### Full Studio — Story Bible, Dual-Mode Story Graph, Pro Cover Studio & Collaboration
1. **Story Bible & Dual-Mode Story Graph**: Keep character, faction, item, location, lore, storyline, and scene cards linked with two-way **Auto-Sync Book** (`[[wikilinks]]` and `#tags`). Switch between **Spatial Storyboard** (Act Group frames, 5 curated board surface themes including Obsidian Dots, Slate Blueprint, Warm Paper, Charcoal Solid, and Ivory Grid, 90-degree obstacle-avoiding elbow connectors, Minimap, `.canvas` JSON import/export) and **Force Graph** (60 FPS physics constellation, hop isolation, shortest narrative path tracing).
2. **Book Cover Studio & Author Seals**: On both website and desktop, design front, spine, back, and jacket flaps with 100-step undo/redo, 10%–500% zoom, `Space+Drag` panning, 8-point scaling and rotation handles, `Ctrl+G` layer grouping, magnetic snapping guides, and `PNG 1x/2x/3x`, transparent PNG, JPEG, Vector SVG, `.docx`, and Print PDF exports. **In the Desktop App**, Book Cover Studio adds full vector illustration & design tools: **Freehand Brush & Vector Pen path drawing**, per-layer transparency & **7 blend modes** (`Normal`, `Multiply`, `Screen`, `Overlay`, `Soft Light`, `Darken`, `Lighten`), direct **`https://` Image URL pasting**, **Draft Variants with Side-by-Side Comparison**, and canvas **Review Pins + `.qvdesign` sharing**. Keep multiple books in **Library**, record your **Origin Author & Device Key**, and seal your **Work Copyright**.
3. **Co-Authors & Imports**: Pair co-authors using verified device tokens in **Collaborate**, or import `.docx`, `.html`, `.rtf`, `.md`, `.txt`, and older `.quillvibe`/`.bookvibe` files in **Settings -> Publishing & Archive**.

## 6. Quillvibe File Formats, Password Locks & Author Keys

Native Quillvibe files use a protected binary format that only Quillvibe reads, with optional password locking so private drafts stay safe.

| Extension | What It Saves | Double-Click Action (Desktop App) |
| :--- | :--- | :--- |
| **`.qv`** | Complete Book Workspace | Opens your manuscript, Story Bible, Story Graph, cover design, proofreading marks, snapshots, Author Key, and Copyright Seal. |
| **`.qvbible`** | Story Bible Notes | Merges Characters, Locations, Lore, and custom categories into the open book. |
| **`.qvscene`** | Single Scene Draft | Opens or imports one scene with its snapshots and proofreading marks. |
| **`.qvstyle`** | Typeset & Paper Style | Applies trim size, font, drop caps, smart quotes, margins, and paper theme. |
| **`.qvdesign`** | Editable Cover Design Package | Opens or merges Book Cover Studio layers, vector paths, blend modes, draft variants, and canvas review pins. |

Older `.quillvibe`, `.qvibe`, `.qvbook`, `.bookvibe`, and `.bv*` files do not open by double-clicking, but you can still import them anytime from **Settings -> Publishing & Archive** or the Welcome screen.

More detail: [docs/OFFICIAL-EXTENSION-REGISTRATION.md](docs/OFFICIAL-EXTENSION-REGISTRATION.md) and [docs/GUIDE.md](docs/GUIDE.md).

## 7. Extensions & Add-ons (`.qvext`)

Quillvibe keeps built-in toolkits separate from optional `.qvext` community add-ons. External add-ons are declarative JSON manifests validated against ReDoS and script checks, cannot access the internet, your disk, or your author keys, and always require consent before installing.

- **Developer Portal & Live Validator:** <a href="https://quillvibe.jhonrey.com/developer" target="_blank" rel="noopener noreferrer"><strong>https://quillvibe.jhonrey.com/developer</strong></a> (validate manifests, inspect SHA-256 digests, test in sandbox, and read developer relations details).
- **Upcoming Companion App (Coming Soon):** A dedicated standalone application for coding, testing, and packaging `.qvext` extensions is in planning.
- **Specification Reference:** Read <a href="docs/DEVELOPER-EXTENSIONS.md" target="_blank" rel="noopener noreferrer"><strong>docs/DEVELOPER-EXTENSIONS.md</strong></a>.

## 8. Keyboard Shortcuts

| Keys | Command |
| :--- | :--- |
| `Ctrl / Cmd + Z` / `Y` | Undo / Redo across Manuscript, Corkboard, Outline, Bible, Graph, and Cover Studio |
| `Ctrl / Cmd + S` | Save Revision Snapshot in Manuscript view; export default format in other views |
| `Ctrl / Cmd + O` | Open any `.qv`, `.qvbible`, `.qvscene`, `.qvstyle`, or `.qvext` file |
| `Ctrl / Cmd + B` / `I` | Bold / Italic formatting around selected text |
| `Ctrl / Cmd + Shift + N` *(Desktop)* | Open current book in a new desktop window |
| `Ctrl / Cmd + W` *(Desktop)* | Close the active book tab (when multiple tabs are open) |
| `Ctrl / Cmd + =` / `-` / `0` *(Boards)* | Zoom in, zoom out, or reset/fit viewport in Book Cover Studio & Story Graph (trackpad pinch supported) |
| `Ctrl / Cmd + Shift + F` | Toggle Zen Focus mode |
| `F11` *(Desktop App)* | Toggle fullscreen focus mode with movable clock, sprint timer, word count, and alarm |
| `F1` | Open Help & Icon Guide |
| `Esc` | Close pop-up windows, menus, tours, or exit Zen Focus |
